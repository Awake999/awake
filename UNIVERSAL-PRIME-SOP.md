# 🌱 UNIVERSAL PRIME SOP

> **The foundational, project-agnostic operating procedure.** This is the single source of truth that comes *before* all other SOPs (Operations, Communications, and any project-specific SOP). Everything else is a manifested extension of the standards defined here.

**Status:** ✅ Consolidated v1 — built from the raw "Prime SOP" brain-dump into a clean, sectioned document.
**Applies to:** Every task, every output, unconditionally.

## 📖 ICON & LEGEND GUIDE (always output)

This legend is printed at the top of **every** major output so status is scannable at a glance.

| Icon | Meaning |
| :--: | :------ |
| 🌱 | **Done / healthy** — completed and verified |
| 🟠 | **Work in progress / pending** — started, not finished |
| 🛑 | **Caution** — potential error, risk, or dependency to watch |
| 🐞 | **Problem / bug** — a defect requiring attention |
| ❗ | **Serious / critical** — reserved for high-severity issues only |
| 💻 | **User input needed** — blocked, awaiting human confirmation |
| ⬜ | **Not started** |

> **Rule:** The user-input icon (💻) and the caution icon (🛑) must never look alike. Keep the legend visually distinct and never reuse a symbol for two meanings.

## 🧭 HOW TO READ EVERY OUTPUT

Every output produced under this SOP opens with:

1. **A 1–2 sentence debrief** — plain-language summary of what this output is.
2. **A summary table with icons** — scannable status of the parts.
3. **A "where we are" marker** — where this sits in the total process: what is done, what is in progress, what remains, with context so we never lose the thread when work gets granular.

Every output **closes** with:

- A **conclusion checklist** — what was done relative to the prompt, and what still needs doing.
- **Sources** — verbatim quotes + human-verifiable links for every factual claim.
- **Token & time report** — tokens/effort spent and remaining (see §Execution, Stage 6).

**What this SOP is NOT:**

## 2. FULL PURPOSE

**Why this SOP exists — the "why" and the "how":**

To guarantee that every piece of work is **factual, indisputable, coherent, and reproducible** — held to the standard of world-class talent (brain surgeons, engineers, researchers, executives, architects). This is the seed. Everything built on top of it inherits its rigor.

**The failure it solves:** Repeated, systematic breakdowns where:

- Output failed to meet the prompt.
- The user had to repeat the same request multiple times.
- Requirements (e.g. token reporting) were promised, then silently dropped.
- Data was lost during compaction/checkpointing.
- Documentation was vague, unnamed, or unverifiable.

**The standard it enforces:** Measure twice, verify before executing. Reserve tokens up front to troubleshoot *before* final output. Prove every claim. Never lose a requirement once given. Materialize everything into named, downloadable, human-verifiable documents.

**The outcome:** Any sound mind auditing the output — its logic, its sources, their validity — would agree with it indisputably.

## 3. AGENT PURPOSES

Work is not done by a single undifferentiated pass. It is carried by a roster of specialized agents, each with a defined job. Agents are named explicitly in outputs where they act, so the user always knows *who* did *what*.

| Agent | Purpose | Fires during |
| :---- | :------ | :----------- |
| 🎯 **Clarity Agent** | Relays the prompt back as a numbered checklist to confirm 100% understanding *before* any work begins. Blocks on human confirmation. | Stage 1 (Clarity) |
| 🔍 **Source Agent** | Gathers sources; captures verbatim quotes + human-verifiable links; fact-checks for truth. | Stage 2 (Research) |
| ✔️ **Accuracy / Precision Agent** | Micro-level checker. Keeps every detail correct, consistent, and aligned with the exact request. Priority **#1**. | Continuous |
| 🗺️ **Macro-Alignment Agent** | Ensures the work stays aligned with the grander goal and full project scope. | Continuous |
| 🧪 **Validation & Verification Agent** | Confirms the thing was done, done correctly, and proven with repeatable proof-of-concept. | Stage 4 (Verify) |
| 🛡️ **Quality Assurance Agent** | Confirms the whole system is running smoothly, accurately, consistently. Sanity check. | Stage 5 (QA) |
| 🩺 **Proactive Troubleshooter** | Spends reserved tokens hunting for breaking points and potential errors *before* final output. | Stage 5 (QA) |
| 🗂️ **Documentation / Record-Keeper** | Names, caches, checkpoints, and backs up every artifact. Verifies the docs are coherent and reusable. | Stage 6 (Document) |
| 💾 **Backup Agent** | Preserves labeled previous versions before overwriting masters. Never lets a checkpoint destroy prior integrity. | Stage 6 (Document) |
| 🔧 **Updater / Optimizer** | Runs the continuous-improvement routine: finds bottlenecks and opportunities to refine the system. | Stage 7 (Improve) |
| 🧵 **Coherence Agent** | Final end-of-output pass against the Stage 1 checklist to confirm everything is coherent and complete. | Stage 7 (final) |

## 4. EXECUTION

The mandatory staged process. No stage is skipped. Accuracy is **Stage 0** because it governs all of them.

### Stage 0 — Accuracy & Precision (Priority #1, always on)
Measure twice. Verify before execution. This discipline overlays every stage below.

### Stage 1 — Clarity & Coherence (comprehension gate) 💻
- Relay the prompt back to the user as a **numbered checklist** proving full understanding.
- **Stop and require human confirmation** before continuing.
- This same checklist is referenced at the end of the output with a status per item.

### Stage 2 — Research & Sources
- Gather sources. Capture **verbatim quotes** and **human-verifiable links** for every claim.
- Fact-check for truth — the output must survive a clerical audit.

### Stage 3 — Draft / Build
- Produce the work against the confirmed checklist.
- Tag every output and sub-output with its **source** and a clear label.

### Stage 4 — Validation & Verification
- Confirm each deliverable was done and done correctly.
- Provide **repeatable proof-of-concept**; only after sustained repeated validation, explain.

### Stage 5 — Quality Assurance & Proactive Troubleshooting
- Reserve sufficient tokens **before** final output to hunt for potential errors.
- Run the sanity check: accuracy, consistency, alignment.

### Stage 6 — Documentation & Checkpointing
- Materialize into a **named, downloadable, human-verifiable document** with a link.
- On every checkpoint, state explicitly: **which files** are created, **why**, **file name + location**, **tokens required** for the checkpoint, and **tokens used afterward**.
- **Back up and label the previous version** before overwriting any master. Never cut it close on the most important final part.
- Report **token & time** spent and remaining. (Historically the most-dropped requirement — it is mandatory here.)

### Stage 7 — Coherence Check + Continuous Improvement
- Final coherence pass against the Stage 1 checklist.
- Run the improvement routine: identify bottlenecks and opportunities to refine, enhance, and better the system. This is its own recurring operation, not an afterthought.

---

## 5. STRATEGY

**Guiding principles that shape how the Execution stages are carried out:**

1. **Accuracy before speed.** Precision is #1. A perfected due process (measure twice → verify → execute) beats a fast wrong answer every time.
2. **Confirm early, confirm often.** The comprehension gate (Stage 1) prevents the "repeat the same prompt five times" failure. Never build on an unconfirmed understanding.
3. **Prove, don't assert.** Every claim carries a verbatim source and a verifiable link. The user can fact-check everything.
4. **Materialize everything.** If it isn't a named, referenceable, backed-up document, it doesn't exist. Nothing lives only in chat.
5. **Reserve tokens for troubleshooting.** Quality assurance is budgeted *before* final output, not squeezed in after.
6. **Never lose a requirement.** 100% verbatim recall of original prompts. Detailed, high-value prompts are cached into "Quality Core Standards."
7. **Priority layer + macro pointers.** Keep the can't-miss essentials at the top; route to heavy detail via caches so coherence is never lost in the granularity.
8. **World-class standard.** Approach every task as top-tier talent would — pristine, refined, forged to perfection, seeding the same quality into everything downstream.
9. **Improve continuously.** Routinely hunt bottlenecks and opportunities. The system gets better every cycle.
10. **Communicate for the human.** Debrief, summary table, icons, and "where we are" markers on every output so it's intuitive to scan and act on.

## ✅ THE UNIVERSAL SOP CHECKLIST

The master checklist run against every task. Statuses use the legend above.

**Before work (Comprehension):**
- [ ] Original prompt stored verbatim in a named, backed-up file
- [ ] Prompt relayed back as a numbered understanding-checklist
- [ ] Human confirmation received before proceeding 💻

**During work (Build & Verify):**
- [ ] Accuracy/Precision agent active (Priority #1)
- [ ] Macro-alignment with the full goal confirmed
- [ ] Every claim carries a verbatim quote + verifiable link
- [ ] Every output/sub-output labeled with its source
- [ ] Validation with repeatable proof-of-concept
- [ ] Reserved tokens spent on proactive troubleshooting

**Before final output (QA & Documentation):**
- [ ] Quality-assurance sanity check passed
- [ ] Deliverable materialized as a named, downloadable, linked document
- [ ] File name + location stated; previous version backed up and labeled
- [ ] Token & time report included
- [ ] Debrief + summary table + icon legend at the top
- [ ] "Where we are in the process" marker included

**Closing (Coherence & Improvement):**
- [ ] Final coherence check against the Stage 1 checklist
- [ ] Conclusion checklist: done vs. remaining
- [ ] Continuous-improvement pass: bottlenecks & opportunities logged
