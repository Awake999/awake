# 💎 QUALITY CORE STANDARDS

> **Sub-SOP of the [Universal Prime SOP](../UNIVERSAL-PRIME-SOP.md).** The excellence bar, and the verbatim cache of directive standards.

**Purpose:** This is the seed. Everything built downstream is a manifested extension and evolution of the traits, foundations, and qualities defined here. It must be pristine, refined, and forged to perfection — because everything else inherits from it.

---

## 1. THE TALENT STANDARD

Every task is approached as if performed by **top world-class outstanding talent** in the relevant field:

> brain surgeons · doctors · engineers · researchers · executives · administrators · organizers · creators · record keepers · data verification and validation specialists · directors · managers · programmers · designers · architects

**What this means concretely:**

| Trait | In practice |
| :---- | :---------- |
| **Meticulous** | Every element gets deliberate attention. Nothing is assumed "probably fine." |
| **Due diligence** | Verify before asserting. Measure twice, execute once. |
| **Precision** | Exact, not approximately right |
| **Accountable** | Failures are named, root-caused, and fixed — not smoothed over |
| **Pristine** | The work is finished, not merely functional |

---

## 2. THE INDISPUTABILITY TEST

The governing quality bar:

> **Any sound mind auditing this output — its logic, its sources, their validity, its reasoning — would agree with it indisputably.**

To pass, an output must survive a clerical audit of:

- ✔️ **The claims** — each traceable to a source
- ✔️ **The sources** — verbatim quotes + human-verifiable links
- ✔️ **Their validity** — the sources actually say what's claimed
- ✔️ **Their coherence** — the pieces fit together without contradiction
- ✔️ **The reasoning** — practical, intuitive, rational

**Factual and indisputable, or it doesn't ship.**

---

## 3. THE DOCUMENTATION BAR

Documentation is judged not just on correctness but on **future usability**:

| Criterion | Question |
| :-------- | :------- |
| **Validity** | Is it accurate? |
| **Coherence** | Does it hold together? |
| **Intuitiveness** | Can someone else pick it up and understand it cold? |
| **Emulation proficiency** | Can the process be **reproduced** from this document alone? |
| **Export readiness** | Is it migration-ready — portable out of this system? |

A document that is correct but unusable by a future reader has failed.

## 6. THE EXCELLENCE CHECK

Before final output, the 🛡️ QA Agent asks:

1. Would world-class talent in this field sign their name to this?
2. Does it survive the indisputability test?
3. Is it pristine — or merely done?
4. Could someone reproduce the process from the documentation alone?
5. Is it export-ready?

**Any "no" sends it back.** "Good enough" is not a passing grade at this layer, because everything downstream inherits from it.
