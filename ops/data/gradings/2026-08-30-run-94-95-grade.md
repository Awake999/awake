## ⚠️ LIMITATIONS — why it keeps happening + the automatic fixes (plain)
1. **Turn breaks eat closings.** When a work turn ends on a tool call (session resumption, context events), the closing reply with buttons never renders. *Auto-fix:* SOP rule — compose the user-facing reply in the SAME turn as the last tool call; a commit is never the last act.
2. **Compaction forgets fresh habits.** New format rules born in chat die at compaction. *Auto-fix:* every rule is written into SOP/CLAUDE.md the moment it's ratified (done tonight) — sessions reload them from disk, not memory.
3. **Chat vs GitHub render differently.** Line breaks that look right in one collapse in the other. *Auto-fix:* only render patterns that survive BOTH (numbered line + indented sub-bullet), specified in the checklists README.
4. **Platform withholds raw thinking.** Unfixable by us. *Auto-fix:* the labeled reasoning digest replaces it, automatically, every run.
