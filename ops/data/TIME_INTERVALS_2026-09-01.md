## ⚠️ READ THIS FIRST — what this is and isn't
**This is an event timeline, not sampled activity.** True 10-minute *sampled* activity (keystroke/app cadence per interval) exists only inside the [Teramind dashboard](https://ascendprimew.us.teramind.co/v2/dashboards/overview) — its API token is local-only, so a cloud session cannot read it. What follows is every **timestamped event** that is reachable, bucketed to 10 minutes: Slack posts, calendar blocks, call recordings, EOD self-reports. Where a bucket is blank, that means **no timestamped artifact**, NOT idleness — most work leaves no timestamp.
