## Alan's words — the process checklist (verbatim, unedited)

```
PROCESS CHECKLIST
0. Greeting
0.5 Purpose
1. How much funding do they need?
2. How do they plan on using / investing the funding?
3. What have they tried so far?
4. How soon do they need it?
5. Credit Score?
6. Summary + Transition / Qualification
7. Pull Back
8. Set appointment
9. Future Pace (Positive Dream Outcome)
10. Secure Credit Report
11. Confirm Appointment time
12. Set proper expectations & requirements for the upcoming call
13. Final confirmation + close out + questions
14. Future Pace (excitement for the next call → their dream outcome)
```

## How transcripts get scored against it (Lane 2, per Alan 8/31: "analyze everything that's been asked on that triage call")

Per call transcript, one scorecard row:

| Field | What counts |
|---|---|
| **Core questions 1–5** | Each scored asked / not asked / partially, with the transcript line quoted: funding amount · use/investment plan · what they've tried · timeline · credit score |
| **Process steps 0–14** | Each present / absent (greeting, purpose, summary+transition, pull back, appointment set, future pace ×2, credit report secured, confirmation, expectations, close-out) |
| **Extra triage** | Anything probed beyond the checklist, quoted |
| **Booked?** | Appointment set on/after the call (cross-checked against GHL bookedAt) |
| **VERDICT** | **FULLY TRIAGED** = all 5 core questions + the process run · **PARTIAL** = some core questions, process incomplete · **CONTACT ONLY** = connected call, no triage content · every verdict links its transcript |
