# 👋 Start Here — the APW Archive, explained for humans

**TLDR:** This is the permanent, verbatim memory of Ascend Prime Wealth — every call, every Slack message, every voice note, saved forever and organized so you can find anything in a few clicks. This page tells you where everything is, how it's organized, and how to move around. Every step is a clickable link — you never need to copy-paste a path or an ID.

---

## 1. What this is

Everything the business says and does gets captured somewhere — Fathom records calls, Krisp records calls, Zoom records calls, Slack holds chats and voice notes, GHL holds client messages. Those platforms can lose things, change plans, or lock you out. **This archive is the hard copy**: the original words, stored in plain files, backed up four ways at once (GitHub cloud, your local computer, Obsidian, Google Drive pointer).

Two rules govern everything in here:
- **Verbatim** — originals are never summarized-over. Summaries exist, but always *beside* the original, never instead of it.
- **Never lost, never overwritten** — files are only ever added. If two versions of something exist, both are kept.

## 3. How everything is organized (the shape of the tree)

```
START-HERE (you are here)
 ├── calls/            one folder per recorded call, grouped by platform
 │    ├── fathom/INDEX → 2026-08-26--michael-moore-guaranteed-funding--176802936/
 │    │                    ├── transcript.md   (verbatim words, in 10-min chapters)
 │    │                    ├── summary.md      (the short version, beside — not instead)
 │    │                    ├── meta.md         (who/when/links)
 │    │                    └── transcript-raw… (untouched original API response)
 │    ├── krisp/INDEX  → same folder anatomy
 │    └── zoom/INDEX   → same folder anatomy
 ├── slack/
 │    ├── channels/INDEX → one export file per channel per period, chronological
 │    └── audio/README   → the .m4a voice notes + a transcript beside each one
 ├── people/README     → one page per person, linking everything they touch
 └── ghl/README        → client-message deposits from the office PC
```

Folder names always read the same way: **`date--what-it-is--source-id`**. You never need the ID — but it's there so nothing is ever ambiguous.

## 4. How to navigate (the three moves)

1. **Go down:** start at a hub → click a category → click an index row → you're at the thing itself. Long transcripts open with a **Contents** list — click a chapter instead of scrolling.
2. **Go back:** every page has a 🧭 breadcrumb line at the top — click it to jump back up to its index, its category, or straight back here.
3. **Cross over:** summaries link to their transcripts, transcripts link to the original recording on the source platform, people pages link to calls, call metas link to people. Follow whatever thread you're curious about — everything connects.

**If you only remember one thing:** every index has an "Archived" column — ✅ means click it and read the words; a plain title link means the original still lives only on the source platform (and clicking the title takes you there).
