### Dispute Process Standardization

  - [**Problem:** Confusion over dispute package terminology and contents was causing inefficiencies.](https://fathom.video/calls/784176539?tab=summary&timestamp=4813.0)
  - [**Solution:** Standardize on two packages, each containing a written statement, disputed accounts list, ID, SSN card, and proof of address.](https://fathom.video/calls/784176539?tab=summary&timestamp=5441.0)
      - [**Version 1 (Identity Theft Complaint):** The original, more complex package.](https://fathom.video/calls/784176539?tab=summary&timestamp=4624.0)
          - [**Round 1:** Includes an Identity Theft Complaint.](https://fathom.video/calls/784176539?tab=summary&timestamp=9092.0)
          - [**Round 2:** Adds a Police Report if a bureau (often TransUnion) pushes back. This is sent later to avoid initial delays.](https://fathom.video/calls/784176539?tab=summary&timestamp=3314.0)
          - [**Rationale:** Uses a cursive font (Sacramento) to bypass automated systems that auto-deny common dispute letters.](https://fathom.video/calls/784176539?tab=summary&timestamp=4662.0)
      - [**Version 2 (Data Breach Statement):** The new default for its efficiency.](https://fathom.video/calls/784176539?tab=summary&timestamp=4086.0)
          - [**Key Difference:** Replaces the Identity Theft Complaint with a Data Breach Statement.](https://fathom.video/calls/784176539?tab=summary&timestamp=4017.0)
          - [**Benefit:** Faster, as it avoids the delays of notarization and waiting for an official police report.](https://fathom.video/calls/784176539?tab=summary&timestamp=3354.0)

### Experian Report Selection

  - [**Problem:** Using the standard Experian consumer report misses critical data needed for comprehensive disputes.](https://fathom.video/calls/784176539?tab=summary&timestamp=8713.0)
  - [**Solution:** Use the Experian Dispute Center report.](https://fathom.video/calls/784176539?tab=summary&timestamp=8713.0)
      - [**Rationale:** It contains significantly more information (e.g., 30+ addresses vs. 6), enabling more thorough removals.](https://fathom.video/calls/784176539?tab=summary&timestamp=8713.0)
      - [**Access Path:** `Credit` tab → `Credit Report` → `Quick Actions` → `File Dispute`.](https://fathom.video/calls/784176539?tab=summary&timestamp=8195.0)
